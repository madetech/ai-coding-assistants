# ai-coding-assistants
What are our principles for using AI coding assistants in our work at Made Tech?

## Core principles
1) Client first
2) Follow the Made Tech Engineering Principles
3) Think about what business context you can give it
4) Think about [AI coding approaches](#ai-specific-principles)
5) Think about tooling

## AI-specific principles
1) Human in the loop
2) Quality
3) Attribution
4) Risk mitigation
5) Consider diverse use cases
6) Context and tooling
7) Client alignment
8) Repeatability
