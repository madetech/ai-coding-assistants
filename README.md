# ai-coding-assistants
What are our principles for using AI coding assistants in our work at Made Tech?

## Core principles
1) Client first
2) Follow the [Made Tech Engineering Principles](https://docs.google.com/document/d/18NSroSqPN1ynBjxzwnqf1TgnduAXSAdl5qnyB5dLOPw/)
3) Think about what business context you can give it
4) Think about [AI coding approaches](#ai-specific-principles)
5) Think about tooling

## AI-specific principles
1) Human in the loop
2) Quality
3) Attribution
4) Managing security risks
5) Consider diverse use cases
6) Context and tooling
7) Client alignment
8) Repeatability
9) Learning with AI and avoiding skill erosion
10) [Use in Legacy Codebases](principals/legacy-codebases.md)
