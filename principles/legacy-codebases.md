Leveraging AI coding assistants in the context of legacy codebases
==================================================================

Managing risk
-------------

*   Access to secrets
*   Licensing of generated code
*   Human in the loop
*   Cost - burning through tokens on large codebases
    

Use cases
---------

*   Help understand codebases
*   Fixing bugs much faster
*   Tackling technical debt
    *   Addressing gaps in test coverage
    *   Refactoring code before making changes
*   Identify and remediate security bugs
*   Handling dependency updates with breaking changes
*   Simplify - reduce the volume of code, structure, and architecture
*   Documenting codebases
    
Principles
----------

*   Ensure the agent has sufficient context to make good decisions
*   Work in small chunks, keep the scope tight
*   Tests are critical
    

Challenges
----------

*   Agent not having access to domain knowledge that not in the codebase

Enabling behaviours
-------------------

*   Use it on a clean clone of public codebases
